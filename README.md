# GTA VI Countdown

A single-page, no-build countdown to Grand Theft Auto VI (19 November 2026) with the unlock time for every country.

- Detects your time zone and counts down to your local unlock.
- Lists 221 countries and regions; search, sort, and tap one to put it on the main clock.
- Midnight local time per country; the US and Canada unlock together at midnight Eastern.

Open `index.html` in a browser, or host the repo with GitHub Pages (Settings → Pages → deploy from branch).

Unofficial fan project, not affiliated with Rockstar Games or Take-Two Interactive.
